## 二、评估发现的问题

1. **导航平铺 14 项**：无分组标签，新客户看不出"该从哪开始"。→ 已改三组：供应链 / 单店链路 / 复制体系。
2. **首页名实不符**：标题"八大模块"实际 12 卡，且未按 owner 双体系心智分区；单店链路顺序乱（案例排在雷达前）。→ 已重排为三个分区，链路卡按 ①→⑥ 步进。
3. **链路页孤岛**：雷达→评分→品牌→装配→案例→大屏是核心转化链，但页间只能靠顶部导航回跳。→ 已加链路条（6 页），当前步自动高亮。
4. **手册培训缺失**：供应链 SOP 与加盟培训是"可复制"承诺的落地保障，此前无载体。→ 已建 /playbook/。
5. **入库闭环已通**：雷达/品牌库/生成器 → 中央库（localStorage，前缀 nbo_lib_*），结构与 Cloudflare D1 迁移对齐。

## 三、关联设计（数据流）

- 雷达选品 →（入库按钮）→ 中央库选品库 → 落地评分因子 f1/f4 输入
- 品牌生成 →（保存）→ 策划资产库（KIT-*）→ 中央库 asset tab 展示
- 装配对比 → 加盟体系成本包（8–10 万 RMB 口径一致，汇率锚 2200）
- 2D/3D 孪生 planogram ↔ 案例 56㎡ 样板 ↔ 装配选型（C1 单箱体 18㎡ / C2 双箱体 36㎡）
- 渠道地图机会点 → 中央库选址库 → L3 主理人培训选址实操

## 四、待办（按优先级）

2. 中央库迁 Cloudflare D1（结构已预留），多端同步收藏。
3. 手册培训勾选进度迁 D1，支持店长批量检查。
4. 案例页接入装配对比真实造价（当前金额口径需承包商询价复核）。
