# 三档门店基准

## 500㎡ 社区店

| 指标 | 数值 |
|------|------|
| SKU 数量 | 4,000 – 6,000 |
| 生鲜占比 | 15 – 20% |
| 货架层数 | 4 – 5 层 |
| 主通道宽度 | 1.8 – 2.2 m |
| 补货频率 | 每周 2–3 次 |

## 2,000㎡ 标准店

| 指标 | 数值 |
|------|------|
| SKU 数量 | 10,000 – 18,000 |
| 生鲜占比 | 25 – 30% |
| 货架层数 | 5 – 6 层 |
| 主通道宽度 | 2.5 – 3.5 m |
| 补货频率 | 每周 3–5 次 |

## 5,000㎡ 大卖场

| 指标 | 数值 |
|------|------|
| SKU 数量 | 28,000 – 40,000 |
| 生鲜占比 | 30 – 35% |
| 货架层数 | 6 – 7 层 |
| 主通道宽度 | 3 – 4 m |
| 补货频率 | 每日 / 隔日 |
