# Nusantara Brand OS 双体系拆分与网红快单店体系改造评估

> 状态：评估稿（2026-10-29），待 Owner 批准后按 Phase 改造。汇率演示口径：1 RMB ≈ 2,200 IDR（上线时需标注日期）。

---

## 一、双体系拆分评估

现有 7 个模块按商业逻辑确实分属两套体系，混在一个导航里会让两类客户都找不着重点：

| | 体系一：零售百货供应链体系 | 体系二：快速验证单店（网红快时尚）体系 |
|---|---|---|
| 客户 | 品牌商 / 渠道商 / 经销商 | 加盟商 / 创业者 / 联营伙伴 |
| 单元 | 多 SKU、多门店、多区域 | 单店模型标准化、快速复制 |
| 核心逻辑 | 深度供应链：去化、补货、合规、节庆因子 | 爆品策划 + 品牌机制 + 加盟复制 |
| 现有模块 | 去化大屏（复杂版）、渠道地图、2D/3D 孪生、MILP 空间优化 | 热点雷达、落地评分、案例集装箱店 |
| 对网红经济依赖 | 低（货架逻辑） | 高（传播单元决定生死） |
| 定价逻辑 | 系统服务费 / 渠道佣金 | 加盟费 + 供应链差价 + 管理费 |

**结论：拆。** 导航分两组（供应链体系 / 加盟创业体系），首页加体系入口分流。数据引擎共用同一个 nbo.db，只是消费口径不同——拆的是"呈现与叙事"，不动底层。

## 二、体系二八项缺口逐项评估

### 1. 加盟体系（缺，核心新增）✅ 建议做
- 新引擎 `nbo.franchise`：业态库（时尚零食 / 熟食卤味 / 咖啡 / 奶茶 / 单品爆品店 / 新品快闪），每个业态 = **开店成本包 + 加盟费结构 + 供应链绑定清单 + 回本模型 + 区域保护政策**。
- 成本锚定：**8–10 万 RMB ≈ Rp 176–220 juta**（单店总投资，含加盟费/设备/首批货/装修，拆项呈现）。
- 回本模型：按业态给日销假设、毛利率、固定成本，算回本月数——给加盟商一个"看得懂的账本"。

### 2. 开源品牌策划/设计体系植入（需降级预期）⚠️ 部分可行
- 现实：**没有一个成熟开源项目能"输入概念→输出完整 VI"**。GitHub 上可行的替代：
  - **Style Dictionary**（Amazon 开源，design token 事实标准）→ 把品牌色板/字体/符号做成可编译 token，新增 SKU 低成本延展（正好对应附件《系列延展测试》要求）；
  - 开源 VI 模板 / presentation 模板（如 brand guidelines 类 repo）→ 仅能做参考壳，不宜直接嵌（许可与维护风险）。
- **建议方案**：不嵌第三方 repo，自建「品牌生成器」——把 launch 评分引擎的输出（品类/机制/辣度/等级）翻译成品牌参数（主色/超级符号/包装层级），token 化存储。这比任何现成 repo 都更贴机制型零食逻辑。

### 3. 定价换算（展示层改动，小）✅ 随加盟模块一起做
- 所有成本包同时显示 RMB 与 IDR，引擎按固定演示汇率换算，页面标注"演示汇率，签约以实际为准"。

### 4. 非集装箱快速装配（缺，建议做）✅
- 装配式四方案对比：集装箱改造 / 轻钢模块 / 板房快装 / 店中店改造——成本、工期（15–45 天）、可复制性、适用商圈。
- 与现有案例四档体系并行，不动已有数据。

### 5. 区域全盘 + 渠道地图双模式（改造现有）✅
- 渠道地图加"加盟机会"图层：人口密度 × 竞品密度 × 商圈等级 → 机会热力；已有门店**保护半径**圈（加盟体系必需）。
- 体系一图层（Warung 评分）与体系二图层（加盟机会）切换显示。

### 6. 特权加盟品牌库（缺，建议做）✅
- `franchise_brand` 表：品牌档案（国别/业态/加盟费/供应链要求/培训强度/联系人角色），与地图点位联动。
- "扫描"动作 = 用加盟机会图层匹配品牌适配度，输出"该区域适合引入哪个品牌"的建议。

### 7. 小店版去化大屏（简化版，必做）✅
- 区别于体系一复杂大屏：一屏 5 卡——今日流水/毛利、库存预警（只显示需要行动的）、畅销 TOP5、补货一键建议、损耗/临期。
- 复用现有 dashboard-case.json 管线，新模板 `dashboard-store.json`，引擎已支持同构输出。

### 8. 操作手册 + 培训体系（缺，必须重试=重视）✅
- `/playbook/` 页面：开店 30 天清单（选址→装配→证照→培训→试营业→开业）、日常运营 SOP、食安与 BPOM 合规 SOP、设备维护。
- 培训等级体系：店员 → 店长 → 督导三级认证，每级课时/考核项；可做培训进度追踪的数据结构。

## 三、改造路线（若批准）

- **Phase A（加盟核心）**：导航双体系拆分 + `nbo.franchise` 引擎（业态库/成本包/回本模型 RMB+IDR）+ 加盟品牌库 + `/franchise/` 页面
- **Phase B（落地支撑）**：小店简化大屏 `/store-dash/` + 渠道地图加盟机会图层与保护半径
- **Phase C（体系纵深）**：品牌 token 生成器 + 装配方案对比 + `/playbook/` 手册培训页

每项都有现成引擎/页面可复用，风险低；8 项全部落在既有架构内，无需推翻。
